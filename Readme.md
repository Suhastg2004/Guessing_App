# Guessing App

A simple number guessing game project.

## Overview

This repository is intended for a guessing game application where a user tries to guess a randomly generated number.

## Features

- Random number generation
- User guess input
- Feedback for high/low guesses
- Attempt tracking

This repository is currently in initial setup and will be expanded with source code and run instructions.
